# 路线图（以后升级用）

## 近期（v3.1）
- [ ] **档位自校准**：记录每次升降档的原因，一个月后看哪类任务总被误判（尤其 high ↔ max 边界）
- [ ] **ultra 超时保护**：连续 3 轮 frontier 未收敛 → 强制给默认方案 + 风险 + 回滚
- [ ] 把「五维自评」改成清单勾选，减少模型自欺
- [ ] 档位可视化：任务开头一行 `[max] 目标/对象/边界`，让用户一眼看到我的理解

## 中期（v4）
- [ ] **返工率指标**：用会话日志统计「同一任务重复改动次数」，给本技能一个可验证的效果指标
      一旦有了指标，才谈得上和 TG 合并（TG 只认可度量）
- [ ] 档位与推理 effort 解耦的显式映射表（哪些档建议配哪个 effort）
- [ ] 多语言版本（英文 SKILL.md），便于发给非中文用户

## 远期
- [ ] 与 TG 的自动联动：`tg-cost` 发现某会话反复返工 → 主动建议升档
- [ ] ADR/术语表产出接 `domain-modeling` 的完整流程
- [ ] 支持「用户预设答案」（常见项目类型直接跳答，减少轮次）

## 不做

- 不做成常驻多技能包（必须单技能常驻，否则目录成本上升）
- 不接管方案评审/代码评审（那是 `tg-orchestrate` 与其他技能的事）
