# tg-memlib · 长期记忆库

和 `tg-memory` 分工：那边管**短期**（对话夹），这里管**跨会话仍要保留**的长期/永久层。
核心主张：**不是建三个目录，而是同一批文件加层级判据。**

## 自适应（先探测形态）

- **探测**：`memlib_root` 可写吗；有 `CORE.md` / `INDEX.md` 吗；有 RAG（`kb_search`）和镜像脚本吗。
- **分支 A（完整：CORE + INDEX + RAG + 镜像）**：走全流程，含检索验收。
- **分支 B（纯文本，无 RAG）**：跳过入库与 `kb_search`，验收改用 `grep`。
- **分支 C（共享库）**：每类事实前加 `<user>/` 或 owner 字段，避免互相覆盖。
- **分支 D（只读）**：只给写入方案与 diff 预览，不落盘。
- **都没有**：最小可用 = `CORE.md` + `INDEX.md` 两个文件，先跑起来再补检索。

## 四层模型

| 层 | 放什么 | 存放 | 读取方式 |
|---|---|---|---|
| **L0 永久** | 红线、稳定偏好、关键路径、当前主线 | `CORE.md`（≤4KB） | **每次开工必读**，唯一自动注入块 |
| **L1 长期** | 主题事实：机器、项目、决策、时间线 | 按主题分文件（`01a`/`02`/`03`…） | 只经 `INDEX.md` 按需取 |
| **L2 检索** | 原文与细节 | RAG 索引 / `_sessions/` / `_sources/` | `kb_search` 取片段，禁止整读 >10KB |
| **短期** | 本次会话状态 | 对话夹 `00-card.md`（见 `tg-memory`） | 只在本会话 |

L0 与 L1 的差别不在「重要性」，在**读取频率**：L0 每条都值一次固定前缀开销，L1 只在需要时付费。

## 什么进哪一层（判据）

**进 L0，只认三个信号之一：**

1. 被 ≥3 次不同会话引用或纠正过；
2. 属硬约束（安全、禁令、不可逆操作前置条件）；
3. 每次做决策都要用它（稳定偏好、关键路径）。

**其余一律 L1。** 项目进度、版本号、待办、一次性踩坑 → L1（`02`/`03`）。
**原文、日志、长表格** → L2 或 `_sessions/`，正文只留路径。

**永远不写**：密码/token/cookie/私钥（只写「存在哪」）、过程流水账、未标日期的结论。

## 晋升与降级（手工，不自动化）

- **晋升**：命中上面三信号 → 压成**一行**写进 CORE，原文留 L1，**不搬家、只加指针**。
- **降级**：CORE 条目 90 天未被引用 → 挪回 L1 并留一行指针；L1 180 天未命中且非项目类 → 归档 `_sources/`，不删。
- **不要自动晋升/衰减**：没有引用计数埋点，自动判定会变成误删或误升；先人工跑顺，有埋点再谈。

## 冲突与覆盖

新事实覆盖旧事实时，**不删旧行**：

```text
~~旧值~~ → 新值（YYYY-MM-DD，来源文件）
```

同一结论只在一处维护；CORE 只留一行指针，不复制全文。否则迟早出现两套互不相认的真相。

## 收尾入库链（四步）

```bash
cmd /c <ai-kb>/session-close.cmd   # ①周沉淀 ②RAG ingest ③镜像 ④改动清单+四问
```

**验收三件**：

1. `wc -c CORE.md` ≤ **4096**（超了就是失败，先删再进）；
2. `kb_search <新关键词>` 能命中新结论（命中不了 = 没入库）；
3. 镜像目录里有同名文件（镜像只单向派生，**不许手改镜像**）。

## 失败模式（按出现频率）

| 症状 | 原因 | 处置 |
|---|---|---|
| CORE 越写越长，最后没人读 | 没有晋级门槛，什么都想放 | 只留三信号；超 4KB 先砍再加 |
| 同一个事实在 3 个文件里不一致 | 复制而非指针 | 保留一处，其余改指针 |
| 检索搜不到刚写的东西 | 没跑 ingest | 收尾链第②步；再用 `kb_search` 验 |
| 改完镜像又被同步覆盖 | 直接编辑镜像 | 只改真源，镜像由脚本派生 |
| 「永久层」名存实亡 | 永久的定义是「每次都在场」，不是「很重要」 | 压到 4KB 并强制每次读 |

## 移植与脱敏

- 路径一律用占位符：`${MEMLIB_ROOT}`、`${SKILLS_DIR}`、`${DSH_HOME}`；**不写本机绝对路径**。
- 本机专属配置放 `_local/`（gitignore），正文只留通用做法。
- 公开包内不出现账号、路径、内网信息；示例数据用 `example-*`。
