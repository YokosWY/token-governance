# 视觉规范

宣传册和封面图用的同一套颜色。改的时候对着这张表来，别临时挑色。

## 色板

| 名称 | 值 | 用在哪 |
|---|---|---|
| 纸 | `#FBFAF7` | 页面底色 |
| 纸（表格斑马） | `#F5F2EA` | 表格偶数行 |
| 墨 | `#191B1F` | 表头底色、封面标题 |
| 正文 | `#26282C` | 段落文字 |
| 账簿蓝 | `#2F5D8A` | 章节标题、细线、次级数字 |
| 印章红 | `#9C2B23` | 只给最关键的那个数字用（比如 −42.5%） |
| 灰 | `#6B6A66` | 注释、页脚、次要说明 |

红只出现在一处。多了就变成装饰，失去提示作用。

## 版式

- 章节标题用宋体（SimSun），正文用雅黑。一页里只有标题是衬线，别的都用无衬线。
- 标题上方一条双细线（`#2F5D8A`），不加编号。章节之间不是步骤，编号会误导。
- 表格表头深底反白，数据行斑马纹，不加竖线。
- 提示框用纸色底 `#F1EEE6`，标题用蓝或红，不用整块彩色。
- 页脚只写名字、页码、许可，不用中点分隔。
